# SURVIVAL — 2D Canvas Game

Браузерная 2D-игра про выживание на чистом JavaScript (ES-модули, без зависимостей и сборки).

## Структура

```
index.html                    — каркас: канвас, HUD, DOM-экраны
styles/main.css               — все стили (HUD, экраны, магазин, кнопка ГИПЕР)
src/core/Game.js              — точка входа: игровой цикл (rAF, dt), канвас/DPR,
                                машина состояний, счёт, частицы, HUD
src/entities/Player.js        — игрок: физика, клавиатура/тач-джойстик,
                                неуязвимость, гипер-способность
src/entities/EnemyManager.js  — враги: спавн, поведение (drifter/chaser), коллизии
src/ui/Menu.js                — экраны: меню, магазин, настройки, пауза, геймовер
src/utils/Storage.js          — localStorage: монеты, скины, рекорд, настройки
```

## Запуск

⚠️ **Нельзя просто открыть `index.html` двойным кликом.** ES-модули не работают
через `file://` из-за CORS. Нужен любой статический сервер:

```bash
# вариант 1: Python
python3 -m http.server 8080

# вариант 2: Node
npx serve .
```

Затем открыть `http://localhost:8080`.

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Движение | Стрелки / WASD (ЦФЫВ) | Плавающий джойстик |
| ГИПЕР | Space / E | Круглая кнопка справа |
| Пауза | Esc / P | Кнопка слева сверху |

## Механики

- 10 очков за секунду выживания, +5 за врага, уничтоженного в гипере.
- 1 монета за каждые 10 очков (начисляется в конце раунда).
- ГИПЕР: шкала заполняется за 15 с выживания; активация даёт 4 с
  неуязвимости, увеличенный размер и уничтожение врагов касанием.
- Скины: 4 штуки (0 / 50 / 100 / 200 монет), покупки и выбор сохраняются.
- Сохранение: один JSON-ключ `survival_save_v2` в localStorage,
  с миграцией рекорда из старого ключа `survival_best`.

## Сборка мобильного приложения

Проект — статика без билд-шага, поэтому оборачивается в APK напрямую через
Capacitor:

```bash
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init survival com.example.survival --web-dir .
npx cap add android
npx cap open android   # далее обычная сборка в Android Studio / Gradle
```

Вибрация (`navigator.vibrate`) работает в Android WebView; на iOS — нет, это ожидаемо.
